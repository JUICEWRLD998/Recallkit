# RecallKit

RecallKit is a product-recall communication studio built with
`@unlayer/react-elements`.

The repository is currently at **Phase 0**, which verifies that the same React
application can generate complete email, print/document, and responsive web
artifacts as both standalone HTML and Unlayer design JSON.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run check
```

See [implementation.md](./implementation.md) for the complete project plan and
[docs/phase-0-notes.md](./docs/phase-0-notes.md) for the spike findings.
