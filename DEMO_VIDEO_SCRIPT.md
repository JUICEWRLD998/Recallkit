## Full voice-over script

RecallKit is a code-first product recall communication studio that turns one incident record into three coordinated templates. Instead of creating each communication separately, teams enter their recall information once and instantly generate a customer email, a retailer action bulletin, and a responsive public web notice. The guided editor makes it easy to update the recall title, severity, status, product information, affected batches, safety instructions, remedies, and support contacts. Every change appears immediately in the live preview, helping teams keep important information consistent across every channel. Brand colors can also be customized using the built-in color composer, and the selected palette is automatically applied to all three templates. The email can be reviewed at desktop and mobile widths, while the retailer bulletin includes A4 and Letter previews with a browser printing option. The public notice can be checked across full, tablet, and mobile layouts. RecallKit uses Unlayer Elements to build each template directly in React and render channel-appropriate output for email, documents, and the web. When the template is ready, users can copy its HTML, export Unlayer-compatible JSON, or select Download Template to save the active design as a standalone HTML file. RecallKit makes multi-channel recall communication faster, clearer, and more consistent—all from one shared source of truth.

## Recording notes

- Record at 1080p if possible.
- Keep the pointer movements slow and deliberate.
- Pause briefly after each edit so the live preview change is visible.
- Generate the voice-over first, then rehearse the screen actions against it once before recording.
- Do not show notifications, personal browser tabs, or local file paths in the final recording.
